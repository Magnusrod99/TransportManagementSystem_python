# Transport Management System — Python

**Author:** Magnus  
**Roll No:** 2628

Python console implementation of the Transport Management System.

## Classes
- `Transport` — abstract base class.
- `Vehicle` — inherits from `Transport` and overrides `start_journey()`.
- `TransportMode` — represents transport modes.
- `Route` — stores route details.
- `Schedule` — stores schedule details.
- `AdminMenu` — provides the console menu.
- `main.py` — starts the application.

## Run in VS Code
Open the terminal in this folder and run:

```powershell
python main.py
```

If your system uses the Python launcher, run `py main.py`.

## Notes
- The View Bookings option is a placeholder, matching the other language versions.
- Records are displayed after input but are not stored for later retrieval.
- Save a screenshot of the program output in the `output` folder.
